共同前提
三步都在同一個訓練集 X 上、用同一個 metric μ；最佳化 prompt、產生軌跡、微調都用同一個模型。讓大模型替小模型 bootstrap 也可以試，但不在這篇的範圍。
作者的兩個預期，與一個實驗設計
① 預期一：微調需要答對的軌跡
先最佳化 prompt，能替微調產生更多成功的資料點；BFT 只收答對的軌跡，答對的越多，能學的就越多。
權重先動的策略，第一份資料由 vanilla 產生；
vanilla 答對太少，就湊不出微調資料（表 1 的表說）。
② 預期二：微調後再調 prompt
微調之後再最佳化一次 prompt，能調整整個 LM 程式的行為，得到品質更高的輸出；第 3 步就是在新權重上重新挑示範。
作者說這可能出乎意料：微調常被認為是比較強的工具，而且兩種方法用的是同一組訓練輸入。
③ 每一步都能省略：八種組合
vanilla、Π、Θ、Π→Π、Θ→Θ 五種是基準；
Π→Θ、Θ→Π、Π→Θ→Π 同時用了兩種最佳化，
作者預期這三種會一致勝過前五種。
結果在第 06 卡：最高分多半落在這三種，但不是每一格都贏。
注意：五格依 Algorithm 1 畫。第 3 步的起點是微調後的權重 Θ′ 配原本的 prompt Π，不是 Π′；原文沒有解釋這個選擇。

08 / 08已知的與還不懂的
兩者都重要有了證據，為什麼還沒有答案
第 5、6 節：九組實驗裡，prompt 與權重一起調最常拿到最高分；但作者承認還不理解兩者為什麼都重要。下排是作者列的限制與範圍外的方向
01　先調 PROMPT
先讓 prompt 多答對幾題，
再拿去微調
微調只學答對的軌跡；vanilla 答不對的任務，
權重先動就沒有資料可學（表 1 的「–」）。
先用 BFRS 讓答對的軌跡變多，BFT 才有東西學，
這正是作者的第一個預期。
✗ 直接拿 vanilla 的輸出去微調
✓ 先挑示範，再用答對的軌跡微調
02　微調之後再調一次
權重換了，
示範要在新權重上重挑
Algorithm 1 的第 3 步在微調後的權重上重新找示範；
作者說這一步能調整程式的行為。Iris 上的 Π → Θ 是 30.7、26.7、44.0，加上最後一步的 Π → Θ → Π 回到 52.7、65.3、79.3。
✗ 微調完就收工
✓ 在新權重上再跑一次 BFRS
03　同一種材料
兩步都靠 metric
篩過的軌跡
不需要中間步驟的標籤：程式自己跑，
metric 只看最終答案，答對的那幾次就是示範，
也是訓練資料。所以 metric 是唯一的篩子，
推理錯、答案對的軌跡也會留下，
附錄 A 那條 Foster's rule 的軌跡就是一例。

① 三個任務乘三個 LM 之外，別的任務、程式或 LM 可能以預料不到的方式改變結果。② 權重只試過對預訓練模型做 LoRA；原則上可能有別的微調方法強到不再需要 prompt 最佳化。③④ 兩者在多階段程式裡的角色都很新，元件之間可能有預料不到的交互；梯度下降已經研究了幾十年。⑤ 第 3 節說讓大模型替小模型 bootstrap 可能更好，但不在這篇的範圍。
