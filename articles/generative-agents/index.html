GENERATIVE AGENTS · INTERACTIVE SIMULACRA · 圖卡＋教材整合版

代理要可信， 先要有記憶記憶流記下一切， 檢索挑出幾筆， 反思與規劃再寫回去

2023 年的大型語言模型已經能在單一時刻演出像人的反應，但要讓一個代理連續過好幾天、記得見過誰、說過什麼、答應過什麼，還缺一套管理記憶的架構。這篇論文把代理的每一段經歷用自然語言寫進一條記憶流，每次行動前依近時、重要性、相關性三個分數撈出幾筆，定期把觀察反思成更高層的推論，再把一天的計畫由粗到細拆開。作者讓 25 個這樣的代理住進一個類似《模擬市民》的小鎮，只告訴其中一位她想辦情人節派對，兩天後就有 5 位代理準時到場。每章開頭先放一張圖解卡講重點，往下是詳細作法；想速讀就切到「只看圖卡」。

Prologue · 整理者的引言

記憶放在模型外面，每一步只撈需要的幾筆

Stanford CS 329Z 第 4 週「Agent Memory Architectures」那一講，談短期與長期記憶、記憶當成工具動作、檔案系統當外部記憶、結構化記憶，以及跨 agent 的記憶。這篇 2023 年的論文是那一講的選讀：它把一套完整的長期記憶架構放進 25 個代理的小鎮，連續跑了兩天。

一個代理只要活得比一次對話長，就會碰到記憶問題：經歷越積越多，context window 裝不下，也不該全部裝進去。這篇論文的答案是把記憶放在模型外面。一條用自然語言寫的記憶流，完整記下代理看到、做過、想過、打算做的事；每次要行動，再依當下的情境撈出一小部分放進 prompt。它還加了兩個會把東西寫回記憶的動作：反思，把觀察歸納成更高層的推論；規劃，把一天拆成可以執行的行動。這一講要談的記憶架構，這篇幾乎每一塊都碰到了。

論文從一個很老的願景講起。四十多年來，做遊戲、認知模型與虛擬環境的研究者，都想要能替人類行為代言的程式角色：它們的行動和自己過去的經歷一致，對環境的反應合理。作者列出這種模擬的用途：讓虛擬社群有真實的社交現象、讓人練習少見卻困難的人際場面、檢驗社會科學的理論、當作可用性測試裡的人類模型、支撐無所不在運算（ubiquitous computing）的應用與社交機器人，以及在開放世界裡處理複雜人際關係的遊戲角色。

難處在於人的行為空間又大又複雜。大型語言模型已經能在單一時間點模擬人的行為，但作者認為，要讓代理長時間維持一致，需要一套架構管理不斷長大的記憶：新的互動、衝突與事件一直出現又淡去，多個代理之間的社交連鎖反應也要處理。這需要三種能力：撈回很久以前的相關事件，把記憶反思成更高層的推論，再用這些推論做出當下合理、放長看也合理的計畫與反應。

第 4 節介紹每個元件之前，都先舉一個「沒有它會怎樣」的例子，正好對上這三種能力。把 Isabella 所有的經歷摘要成一段塞進 prompt，問她最近熱衷什麼，她只會說「活動與專案的合作」「咖啡店的整潔」這類空泛的話；改成依問題撈出相關的記憶，她會說自己熱衷讓人感到被歡迎、策劃活動，例如情人節派對。只給 Klaus 觀察型的記憶，問他最想和誰相處一小時，他會挑互動次數最多的 Wolfgang，但兩人只是在宿舍擦肩而過。只把 Klaus 的背景與現在的時間交給模型，問他此刻該做什麼，他會在 12 點吃午餐，12 點半再吃一次，1 點又吃一次。

三個失敗各自對應架構的一個元件：記憶流與檢索、反思、規劃。第 2.3 節把同一個問題講成文獻的缺口：既有的做法多半是「第一階」的提示模板，例如 few-shot 或 chain of thought，只依據代理眼前的環境產生行為；可信的代理還得依據大量的過去經驗，這對第一階提示很不合適，以當時模型的 context window 來說甚至做不到。先前也有人替語言模型接上靜態的知識庫加資訊檢索，或用簡單的摘要延長記憶；這篇要處理的經驗在每個時間步都會更新，而且要和代理當下的情境與計畫混在一起，兩者可能互相強化，也可能互相矛盾。

提醒

評估的是可信度，不是任務成功率

這篇論文沒有要代理完成某個有標準答案的任務。它問的是：行為看起來像不像一個依自己意志過日子的人。所以第 9 章的評估方法是訪談代理、請人排序哪個回答最可信，而不是算正確率。讀後面的數字時，要記得量尺是人的判斷。

第 2 節先把這篇放進人機互動的脈絡。互動式機器學習讓非專家也能訓練分類器，後來延伸到深度學習與用 prompt 編寫模型行為；另一條線從 SHRDLU、ELIZA 開始，探討用自然語言和電腦互動的機會與風險，也一直在爭論人該把多少事委派給代理。作者說這些線索合起來，代表現在能做出替人類行為代言、又能用自然語言互動的代理，也重新打開 GOMS、Keystroke-Level Model（KLM）這類認知模型、原型工具與無所不在運算的老問題。

可信代理（believable agents）是這條研究的核心目標：像迪士尼電影裡的角色，給人「有生命」的錯覺，看起來依自己的意志做決定。過去它們多半是遊戲裡的非玩家角色（NPC）。Laird 與 van Lent 在 2001 年指出，遊戲世界讓開發者不必處理真實世界的機器人，也不用從零打造模擬環境，就能打磨代理的認知能力。

四十年來的做法，在實作時多半簡化了環境或行為的維度。規則式的做法（有限狀態機、行為樹）是人手一條條寫行為的暴力解，到今天仍是主流，《質量效應》與《模擬市民》系列都用它處理基本的社交互動；但開放世界裡可能的互動寫不完，腳本沒寫到的程序也做不出來。學習式的做法以強化學習為代表，AlphaStar 與 OpenAI Five 在《星海爭霸》與《Dota 2》達到超越人類的表現，但它們的成功多半在有明確獎勵可以最佳化的對戰遊戲，還沒解決開放世界裡的可信代理。

第三條是 Newell 開創的認知架構，也是和這一講關係最直接的一條。Quakebot-SOAR 與 ICARUS 做出第一人稱射擊遊戲的 NPC，TacAir-SOAR 做出空戰訓練模擬裡的飛行員。它們背後的架構不同，原則相同：維持短期與長期記憶，裡面放符號結構，以「感知、計畫、行動」的循環運作，把感知到的環境對上一組人手寫好的行動程序。作者的評語是，它們的行動空間被限制在手寫的程序知識裡，沒有讓代理尋找新行為的機制，所以多半只部署在第一人稱射擊或積木世界這類不開放的情境。

第 2.3 節轉到語言模型。關鍵的觀察是語言模型從訓練資料裡學到了很廣的人類行為，只要給一個範圍夠窄的情境，就能生成可信的行為。作者自己先前的 social simulacra 用一串 prompt 生成社群系統裡的使用者與他們的行為；其他研究複製了社會科學實驗與政治民調、生成合成資料，也有人用語言模型做互動小說、文字冒險遊戲，或把「拿起瓶子」這種任務拆成機器人的動作序列。作者主張語言模型可以是可信代理的關鍵材料，但第一階提示只看得到眼前；這篇的貢獻是替它加上會在每個時間步更新的記憶。

背景

同樣有長期記憶，差在裡面裝什麼

這段對照是整理者加的。認知架構的長期記憶放符號結構，行動要對上人手寫好的程序；生成式代理的記憶流放一句句自然語言，行動由語言模型讀了撈回來的記憶之後生成。前者可以精確比對，但遇到沒有對應程序的新情況就做不出來；後者什麼都能記、什麼都能生成，代價是第 10 章會看到的撈漏與添油加醋。

代理和世界互動靠行動，和彼此互動靠自然語言。每個時間步，代理都輸出一句描述自己正在做什麼的話，例如「Isabella Rodriguez 正在寫日記」；這句話會轉成地圖上的移動，並由語言模型翻成幾個 emoji 顯示在角色頭上，點角色才看得到完整的句子。代理會察覺附近的其他代理，由架構決定要擦身而過還是開始交談，對話是完整的自然語言。作者在註腳承認，這些對話常常顯得太正式，可能是底層模型的指令微調造成的。

使用者有兩種方式和代理說話。一是指定一個自己的身分，例如自稱記者問「誰要參選？」，John 會回答他和朋友 Yuriko、Tom 都在聊這次選舉，決定投給 Sam Moore。二是扮成代理的「內心聲音」，代理比較會把這種話當成指示：以 John 的內心聲音說「你要在選舉中挑戰 Sam」，John 就決定參選，還告訴了太太和兒子。使用者也可以直接進入小鎮扮演一個代理，不論是既有的角色還是沒有任何過去的訪客，其他代理都一視同仁：注意到它、主動互動、記住它的行為再形成看法。

def retrieve(query, memories, budget):
    q = embed(query)
    for m in memories:
        m.recency = 0.995 ** game_hours_since(m.last_accessed)   # 指數衰減
        m.relevance = cosine(embed(m.description), q)            # 餘弦相似度
        # m.importance 在建立時已由模型打好 1 到 10 分
    for key in ("recency", "importance", "relevance"):
        min_max_scale(memories, key)                             # 各自縮放到 0 到 1
    ranked = sorted(memories, reverse=True,
                    key=lambda m: m.recency + m.importance + m.relevance)  # 權重都是 1
    picked = take_until_full(ranked, budget)                     # 塞得進 context window 為止
    for m in picked:
        m.last_accessed = now()   # 整理者的推論：近時算的是「上次被取用」，被撈到就更新
    return picked

Chapter 12 · Boundaries and Errors · Future Work and Limitations · Ethics

記憶一多、時間一長，破綻才浮出來

兩天的模擬暴露了三種怪行為：知道的地點越多越會挑錯地方、自然語言傳不了的常規、太客氣也太配合。作者也坦白列出成本、評估範圍、穩健性與偏誤的限制，以及四個倫理風險。

作者對 Smallville 做了歸納分析，找出三種常見的異常行為，留給後續研究改進：

1
記得越多，越難挑記憶越來越多，不只更難撈出最相關的資訊，也更難決定一個行動該在哪裡做，因為代理知道的地點越來越多。有些代理因此選了不太典型的地點：本來大家都去咖啡店吃午餐，有些代理知道附近有間酒吧後，午餐改去那裡，雖然酒吧原本是傍晚聚會的地方。作者的玩笑是：除非小鎮自己養成了下午喝酒的習慣。
2
常規說不清有些地點的物理規範很難用自然語言傳達。宿舍的浴室一次只能一個人用，但有些代理以為宿舍浴室通常能多人同時使用，有人在裡面也照樣進去；小鎮的店大約下午 5 點打烊，偶爾仍有代理在 5 點後走進店裡。作者認為把常規寫進地點的狀態就能改善，例如寫成「單人浴室」，而不是「宿舍浴室」。
3
太客氣、太配合指令微調似乎讓代理整體更有禮貌、更合作。Mei 和丈夫 John 的對話常以正式的問候開頭、客氣地問他今天過得如何，最後說「一如往常，和你聊天很愉快」。Isabella 收到其他代理各式各樣的派對建議，例如辦莎士比亞朗讀會或專業人脈交流會，雖然和她的興趣不合，她幾乎從不拒絕；久而久之，別人的興趣塑造了她的興趣，被問到喜不喜歡英國文學時，她說自己非常有興趣。

思考題 · 03

你的 agent 的記憶，能被一段對話改寫嗎？

想一個會把使用者說的話存進長期記憶的系統。

先分清楚兩種記憶：代理自己觀察到的事，和別人告訴它的事。論文的記憶流把兩者都當成觀察，所以一段刻意設計的對話就可能被當成事實。可以考慮替每筆記憶記下來源，並在反思或回答時區分「我看到的」與「別人說的」；這是整理者的建議，論文沒有做。

作者的收尾是：這篇介紹了生成式代理，一種模擬人類行為的互動式運算代理；描述了一套架構，提供完整儲存代理經驗的機制，透過反思加深它對自己與環境的理解，再撈出其中精簡的一部分來決定行動；並把代理做成《模擬市民》風格遊戲世界裡的 NPC，模擬它們的生活。評估顯示這套架構產生可信的行為。展望未來，作者認為生成式代理能用在許多互動應用裡，從設計工具、社群運算系統到沉浸式環境。

第 8.1 節舉了兩類應用。一類是更強的社會模擬：作者先前的 social simulacra 只能生成沒有狀態的角色，在論壇上產生討論串；有了生成式代理，論壇、虛擬實境的元宇宙，甚至配上多模態模型的社交機器人所在的實體空間，都能住進有記憶的角色，用來測試與設計社會系統和理論。另一類是以人為本的設計流程，和 GOMS、KLM 這類認知模型的用途相近：作者設想一個代理模擬 Mark Weiser 無所不在運算短文裡的主角 Sal，學會她幾點起床、什麼時候需要第一杯咖啡、典型的一天長什麼樣，於是能自動煮咖啡、幫忙讓孩子準備上學、在她辛苦工作一天後調整音樂與燈光。

成本的數字散在兩處：第 8.2 節說 25 個代理跑兩個遊戲日，要幾千美元的 token 費用、好幾天才跑完；附錄 A 說架構依序執行，大約現實一秒等於遊戲一分鐘。作者點名的後續方向，都整理在第 12 章的表裡。

整理者的讀法

放回這一講：一套記憶架構要回答的四個問題

下面是整理者的連結，論文沒有這樣講。拿這篇對照第 4 週的講題，可以把任何 agent 的記憶設計拆成四個問題。寫什麼：這篇把觀察、反思、計畫全部寫進同一條自然語言的流，連家具閒置都記。取什麼：每一步用近時、重要性、相關性打分，只取放得進 context window 的前幾筆。何時整理：重要性累計到門檻才反思，整理出來的東西附出處、寫回原處。誰看得到：每個代理只看得到自己的記憶，跨代理的資訊只能靠對話傳。這篇沒有讓模型自己呼叫工具去讀寫記憶，也沒有用檔案系統，那是這一講的其他主題；對照起來看，差別在於「何時讀寫」由架構決定，還是交給模型決定。

代理用的是哪個模型？
ChatGPT 的 gpt-3.5-turbo。作者寫論文時 GPT-4 的 API 還要受邀才能用；他們預期模型變強之後，記憶、規劃、反思這些基本元件仍然適用（第 4 節）。
跑一次要花多少？
25 個代理跑兩天，花了幾千美元的 token 費用、好幾天才跑完（第 8.2 節）；架構依序執行，大約現實一秒等於遊戲一分鐘（附錄 A）。
程式碼有公開嗎？
有。第 1 節的註腳給了一個示範模擬的網址，以及模擬程式的公開 repository，放在 GitHub 的 joonspk-research/generative_agents。

Reference · 名詞速查

關鍵名詞與它們在論文裡的位置

先列架構的元件，再列小鎮與環境，接著是評估用的方法與指標，最後是限制裡的名詞。

generative agent
生成式代理
用生成式模型模擬可信人類行為的代理；行為依自己不斷變化的經歷與環境而定（第 1 節）。
believability
可信度
看起來像依自己的意志在做決定與行動；這篇評估的依變項（第 6.1 節）。
memory stream
記憶流
完整記錄代理經歷的資料庫；每筆記憶物件有自然語言描述、建立時間、最近取用時間（第 4.1 節）。
observation
觀察
記憶流最基本的元素：代理直接感知到的事件，包括自己、別的代理與物件的行為或狀態。
reflection
反思
代理自己產生的高層推論，存回記憶流並指向依據；重要性加總超過 150 時觸發（第 4.2 節）。
reflection tree
反思樹
反思也能以反思為對象，所以葉是觀察、越往上越抽象（圖 7）。
plan
計畫
未來一串行動，每筆有地點、開始時間、持續時間；由上而下遞迴拆細，也存進記憶流（第 4.3 節）。
retrieval function
檢索函式
替每筆記憶算近時、重要性、相關性，各自縮放到 0 到 1 後加權相加，取塞得進 context window 的前幾筆。
recency
近時性
距離上次被取用的遊戲時數做指數衰減，衰減因子 0.995。
importance
重要性
記憶建立時請模型打 1 到 10 分；打掃房間 2 分，約暗戀的人出去 8 分。
relevance
相關性
記憶與查詢的嵌入向量之間的餘弦相似度。
agent's summary description
代理摘要
身分、動機、職業與自我評價的一段摘要，由三次檢索加摘要產生，定期更新並快取（附錄 A）。
seed memory
種子記憶
作者替每個代理寫的一段身分描述，以分號切開，各自成為模擬開始時的一筆記憶（第 3.1 節）。
inner voice
內心聲音
使用者扮成代理的內心聲音下指示，代理比較會把它當成要照做的事（第 3.1.2 節）。
environment tree
環境樹
區域與物件存成的樹，邊代表「在裡面」；每個代理只記得自己看過的子樹，選地點時從根往下問模型（第 5.1 節）。
first-order prompting
第一階提示
只依據眼前環境產生行為的 few-shot 或 chain-of-thought 提示模板（第 2.3 節）。
cognitive architecture
認知架構
SOAR、ICARUS 這類架構：有短期與長期的符號記憶，以感知、計畫、行動的循環對上手寫的程序（第 2.2 節）。
ablation
消融
拿掉架構的部分元件來看效果；這篇拿掉反思、計畫、觀察三種記憶的存取（第 6.2 節）。
TrueSkill
多人排名評分
Elo 等級分在多人情境的推廣，把排名換成每個條件的平均值 μ 與標準差 σ（第 6.4 節）。
crowdworker condition
群眾外包條件
人類工作者看過重播與記憶流後，用代理的口吻作答；是基本水準的基準，不是人類的最好表現。
information diffusion
資訊擴散
消息在代理之間透過對話傳開；量測派對與參選兩則消息，兩天後各有 52% 與 32% 的代理知道。
network density
網路密度
互相認識的代理連成邊，密度＝2 乘以邊數，除以節點數乘以節點數減一；從 0.167 升到 0.74。
memory hacking
記憶駭入
用精心設計的對話讓代理相信某件從沒發生的事；作者列為尚未測試的穩健性風險（第 8.2 節）。
