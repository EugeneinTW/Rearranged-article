不必考完整份， 一百道精選題 就估得出分數用舊模型的作答紀錄挑題， 再用試題反應理論補上沒考的題

大型語言模型的基準動輒上萬題，每出一個新模型、每存一個 checkpoint、每換一種 prompt，都要再考一次，成本很高。這篇論文問的是：只考一小部分題，能不能估出整份基準的分數？作者比較三種挑題法，再借用心理計量學的試題反應理論（IRT）預測沒考的題；在 Open LLM Leaderboard、MMLU、HELM、AlpacaEval 2.0 四個基準上，每個情境 100 題，平均估計誤差約 2%。每章開頭先放一張圖解卡講重點，往下是詳細作法；想速讀就切到「只看圖卡」。

Prologue · 整理者的引言

設計基準時，也要算評估的帳

Stanford CS 329Z 第 7 週「Evaluation Fundamentals & Benchmark Design」那一講，談評估為什麼難、一個好基準要有哪些性質。這篇 2024 年的論文是那一講的選讀，處理一個常被略過的問題：基準有上萬題、每個模型都要考完整份時，評估本身就是一筆大開銷；能不能少考幾題，分數還估得準？

CS 329Z 把這一講放在「Evaluation for Agentic Systems」分區。講題從評估為什麼難開始，接著用一個四元組拆解一次評估：要求（request）、環境（environment）、停止條件（stopping criteria）、評分者（scorer），再談每個元件怎麼設計、好 benchmark 有哪些性質、怎麼讓 scaffolding 貼近真實使用，以及可靠度的幾個面向。同一講的必讀是 Zhu 等人的〈Establishing Best Practices for Building Rigorous Agentic Benchmarks〉，另一篇選讀是 Press 的〈How to Build Good Language Modeling Benchmarks〉。

放在這一講裡讀（這是整理者的讀法），tinyBenchmarks 碰到的是評分與可靠度這兩塊：一份基準的分數，是把每一題的評分平均起來；題數越多，分數越穩，每個模型要付的成本也越高。這篇論文換一個方向問：已經有很多模型考過完整份時，新模型只考 100 題，估出來的分數離完整份差多少？這個差距在更新的模型、專門領域的模型身上會不會變大？第 7 到 9 章的實驗設計，本身就是一個「怎麼驗證一種評估方法可不可靠」的範例。

先把幾個統計名詞對齊

  • 估計誤差：用少數題目估出來的分數，和考完整份得到的真實分數差多少。論文的圖大多畫它在一批測試模型上的平均。
  • 偏差（bias）與變異（variance）：偏差是估計值平均起來離真值多遠，變異是同一種估法重抽幾次、結果晃得多厲害。題目抽得少，變異就大。
  • 加權平均：每一題乘上一個權重再加總，權重非負、加起來等於 1。三種挑題法最後都落在這個形式。
  • K-means 分群：把一堆向量分成 K 群，讓每一群的點盡量靠近那一群的中心。
  • Spearman 等級相關（rS）：只比排名的相關係數；1 代表估出來的排名和真實排名完全一樣。

引言從當時的局面講起。LLM 能解的任務越來越多，為了量化與比較這些能力，出現了幾個關鍵的基準：MMLU、Open LLM Leaderboard、HELM、AlpacaEval。這些基準由幾百到幾千道題組成，整個基準加起來常常上萬題，對有數十億參數的模型來說，考一次在算力、環境與金錢上都很昂貴。作者引用 HELM 作者的數字：在 HELM 上評一個 LLM，要超過 4K GPU 小時，改用 API 則超過 1 萬美元。AlpacaEval 這類基準還要一個商用 LLM 當評審，成本又往上加。

更麻煩的是，同一個模型常常要評很多次：預訓練期間要定期評 checkpoint 追蹤進度，也要試不同的 prompt 策略與更大範圍的超參數。每多評一次，就多付一次完整基準的成本。

作者因此重新檢視「一定要在這麼大的資料集上評估」這件事。圖 1 是全文的縮影：在 MMLU 上，只用 100 道挑過的題（不到全部題目的 1%）估每個模型的準確率，再和它考完整份 1.4 萬題的真實準確率比；對 12 月 30 日到 1 月 18 日之間發布的一批新模型，作者表現最好的策略 IRT++ 估出的準確率，平均只差 1.9%。

論文比較了三類策略（第 3、4 節）。第一是 Perlitz 等人為 HELM 提出的分層隨機抽樣，最簡單，但估計誤差可能很大。第二是依已經評過的模型的對錯把題目分群，靈感來自 Vivek 等人的 Anchor Points：要找的是「一個模型答對或答錯這題，就代表它在另一批題也會答對或答錯」的題目；它在某些設定下表現不錯，但對錯模式只是巧合時就不可靠，例如要估一個專精某個領域的模型。第三是作者用 IRT 建的新策略：把 LLM 當考生、基準當試卷，學出每道題需要哪些潛在能力的表示，用這個表示分群，並用 IRT 修正任意一組題目估出的分數。

實驗在四個熱門基準上做：Open LLM Leaderboard、MMLU、HELM、AlpacaEval 2.0。作者的結論是：每個情境 100 道挑過的題，就足以可靠地估出各種 LLM 的表現，平均誤差約 2%。他們據此釋出每個基準的 tiny 版（每個情境 100 題），以及用 IRT 進一步改善估計的工具。

"100 curated examples per scenario are enough to reliably estimate the performance of various LLMs" 「每個情境 100 道挑過的題，就足以可靠地估出各種 LLM 的表現」：引言最後一段的結論句，後面接著「平均誤差約 2%」。

第 2 節先定義名詞。一個基準由幾個情境（scenario）組成，情境可能再分成子情境。原文舉的例子是：MMLU 與 HellaSwag 都是 Open LLM Leaderboard 與 HELM 的情境（附錄 D 列的 HELM Lite 十個情境裡沒有 HellaSwag，這一句照原文寫）；MMLU 自己又有「marketing」「elementary mathematics」這類子情境。作者在註腳說明，MMLU 與 AlpacaEval 各自當成一個情境。情境或子情境由一道道題目組成，題目在 IRT 的文獻裡叫 item，是給 LLM 解的小測驗，從選擇題到文字摘要都有。

模型 l 做完題目 i，基準背後的系統會給一個分數，作者叫它「正確度」，記作 Yil。這篇用到的基準裡，正確度要嘛是二元的 0 或 1（錯或對），要嘛是 0 到 1 之間的數，代表對的程度；後者用在一題不只一個正確答案的情況，例如 HELM 有些情境用 F1 計分。

最終目標是估出 LLM 在整份基準的表現。整份的表現，是各個情境表現的平均（Open LLM Leaderboard、MMLU、AlpacaEval 2.0），或是跨情境的平均勝率 mean win rate（HELM）。所以作者先估每個情境的表現，再照基準的規則彙整。有子情境時，情境的表現通常是各子情境表現的簡單平均。

為了講解方便，正文假設情境的分數就是它所有題目正確度的簡單平均。子情境題數不同時就不是這樣：要讓每個子情境一樣重，得改用加權平均。附錄 A 把這件事寫成式子：子情境 k 裡的每一題，權重是「1 ÷ 子情境的個數 ÷ 這個子情境的題數」，整個情境的分數就是所有題目的加權和。作者的程式把這些權重叫 balance weights，實驗裡也照這個方式算。

要解的問題就是：挑一小部分題目 Îj，讓一個新模型只做這些題，就能估出它在情境 j 的分數。為了聰明地挑，作者假設手上有另一批 LLM 在整份基準上的正確度資料，也就是一群「考過完整份」的舊模型。作者指出，許多熱門基準的這種逐題資料都是免費公開的。下一章的三種挑題法，差別就在怎麼用這份資料。

給初學者

這裡的「訓練資料」長什麼樣

一般機器學習的訓練資料是一堆題目與答案。這裡的訓練資料是一張表：每一列是一個已經考過完整份的舊模型，每一欄是一道題，格子裡是那個模型在那一題的正確度。挑題與擬合 IRT 都只用這張表，不需要題目的文字內容。第 7 章會看到，訓練與測試切的也是這張表的列，也就是模型。

三種方法最後都寫成同一個形式（式 3.1）：挑出的每一題有一個權重，權重非負、加總為 1，新模型在這些題上的加權平均，要接近它在整個情境的平均。差別在怎麼挑題、怎麼給權重。

分層隨機抽樣。分層抽樣是先把資料分組，再從每一組抽，確保每一組都有代表。用子情境當分層，是 Perlitz 等人在從 HELM 抽子集時提出的；他們發現這樣抽，替模型排名的能力不會損失太多。作法是在每個子情境裡均勻地隨機抽，並讓任兩個子情境抽到的題數最多差 1；理由是一次好的評估，每個子情境都該一樣有代表性。每一題的權重都一樣，是 1 除以抽到的題數。

依對錯分群。隨機抽的子集有抽樣本身的不確定性，題目少時更明顯。作者改用分群挑出有代表性的題。Vivek 等人原本的 Anchor Points，是依模型對正確類別的信心把分類任務的題目分群，每群挑一題「錨點」來評估；作者把它改到更一般的設定，讓 MMLU、AlpacaEval 2.0、Open LLM Leaderboard 與 HELM 的所有情境都能用。想法是：如果題目 i 是一個錨點，就該有一大批題目，模型答對它們若且唯若答對 i。具體作法是，每一題用一個向量表示，向量的每一格是訓練集裡某個模型在這一題的正確度，所以向量長度等於訓練模型的數量。對這些向量跑 K-means 分成 K 群，找出離每個群中心最近的那一題，這 K 題就是挑出的題。新模型的估計，是它在這 K 題上的加權平均，每一題的權重是它那一群佔情境題數的比例。

作者說這個方法簡單又有說服力，但有兩個弱點：對錯模式會變（例如隨時間變），所以會受分布偏移影響；訓練模型很多時，向量的維度很高，會碰上維度詛咒，也就是維度一高、距離就不太分得出遠近。

依 IRT 表示分群。第三種方法換掉的是題目的向量：改用第 4 節 IRT 模型學到的題目參數，也就是每一題估出來的 α 與 β。IRT 依題目的難度與答對它需要的能力，給每一題一個有意義的表示。這個向量是低維的（實驗裡最多 16 維），直接解決了維度的問題；如果 IRT 模型合理描述了現實、題目的表示也穩定，它也可能減輕分布偏移。IRT 表示的是哪些題難度相近、需要的能力相近，錨點代表的正是作者想要的東西。權重同樣是錨點那一群佔的比例。

思考題 · 01

你手上有多少個「考過完整份」的舊模型？

想一個你在維護的評估集：可能是一組 agent 任務，也可能是一份內部的 QA 題庫。分群挑題需要一張「模型 × 題目」的逐題作答表，而且列數要夠多，分出來的群才有意義。

如果你只存了每次評估的總分，先改成保存每一題的結果；等累積了夠多個版本或模型，再試著分群挑題。在那之前，照子情境分層抽樣是最不依賴歷史資料的做法。「累積多少才夠」論文沒有給數字，這一段是整理者的建議。

IRT 是一組發展成熟的統計模型，心理計量學用它透過標準化考試（例如 GRE、SAT）量測個人的潛在能力。第 1.1 節提到，IRT 近年也開始用在 AI 與 NLP：有人用 IRT 的潛在變數量語言模型的能力，有人用它研究常用基準的飽和（分不出模型的好壞），也有人發現 IRT 能可靠地預測 LLM 在沒看過的題目上的反應、替題目依難度與鑑別度分類、替模型排名。

第 4.1 節用的是兩參數的多維 IRT 模型。用文字講：模型 l 答對題目 i 的機率，是把「題目需要的能力 αi 和模型具備的能力 θl 的內積」減掉 βi，再用邏輯斯函數壓到 0 到 1 之間。θl 是模型 l 看不到的能力，是一個 d 維向量；αi 也是 d 維，決定答對這一題需要 θ 的哪幾個維度；βi 是一個數，作者說它可以看成偏移項，調節能力為零時答對的機率。β 越大，同一個模型答對的機率越低，所以可以把它讀成題目的難度（這是整理者的讀法；第 3.2 節作者也說，IRT 的表示依據的是題目的難度與需要的能力）。

式 4.1 的文字版 · 教學用示意（整理者寫的） 
def p_correct(theta_l, alpha_i, beta_i):
    z = alpha_i @ theta_l - beta_i      # 能力對上需求的程度，再扣掉偏移（難度）
    return 1 / (1 + np.exp(-z))          # 邏輯斯函數：壓進 0 到 1

擬合出來的題目參數有兩個用途。第一，把估出的 αi 與 βi 接在一起，當作第 3 章分群用的題目向量。第二，下兩章的兩個估計量，都要用它們預測新模型在沒考的題上的表現。

怎麼擬合（第 4.4 節）。作者用變分推論（variational inference）：不直接算出參數的精確分布，而是找一個簡單的分布去逼近它。他們假設 θ、α、β 都服從常態分布，常態分布的平均與精確度又各有自己的先驗（平均是常態分布、精確度是 Gamma 分布），這樣就能用 Lalor 與 Rodriguez（2023）的階層式貝氏模型軟體來擬合。模型與題目的參數，都取變分分布的平均當點估計。維度 d 在 {2, 5, 10, 15} 裡挑：在訓練集裡切出一份驗證集，選讓 IRT 預測得最準的那一個。

分數在 0 與 1 之間時（第 4.3 節）。AlpacaEval 2.0 的分數是有上下界的連續值，可以轉到 0 到 1；HELM 與 Open LLM Leaderboard 也有幾個情境的分數落在 0 到 1 之間。作者的修法很簡單：每個情境選一個門檻 c，把分數大於等於 c 的算成 1、否則算 0，c 的選法是讓訓練資料裡「二值化之後的總和」大約等於「原本分數的總和」。這樣兩者的平均差不多，二值化之後就能用標準的 IRT 工具。

背景

為什麼是內積減掉一個數

傳統的單維 IRT 只有一種能力：能力越高、題目越簡單，答對機率越高。多維版本讓一道題可以同時需要幾種能力，例如一題數學應用題可能同時要閱讀與計算。αi 的每一格說明這一題有多依賴某一種能力，θl 的同一格說明模型在那種能力上有多強，內積就是「這個模型的強項，對不對得上這題的需求」。這一段是整理者補的背景，論文沒有展開。

第一步估能力：把題目參數固定，對新模型實際做過的題，找出讓這些作答結果最可能出現的能力（最大化對數概似），下面叫它「估出的 θ」。題目參數固定之後，這件事就等於擬合一個邏輯斯迴歸，是統計裡研究得很透徹的 M 估計。

第二步估分數。情境分數是隨機的，作者用「已知看過的題的對錯時，情境分數的條件期望值」來近似它，這是均方誤差意義下最好的近似。拆開來看，它等於：看過的題直接用實際的正確度，沒看過的題用 IRT 給的答對機率，全部平均。寫成兩段的加權：權重是看過的題佔情境題數的比例（論文用帶帽的 λ 表示，這一頁寫成「看過的比例」）；看過的比例乘上看過的題的平均正確度，加上沒看過的比例乘上沒看過的題的平均預測機率。把真正的 θ 換成估出來的 θ，就是作者叫做 p-IRT（performance-IRT）的估計量（式 4.3）。

p-IRT · 教學用精簡版（整理者依第 4.2 節寫的，不是論文的程式） 
# 1. 固定題目參數，只估新模型的能力（等於一個邏輯斯迴歸）
theta_hat = fit_theta(y_seen_all, alpha[seen_all], beta[seen_all])   # 可以用所有情境做過的題

# 2. 情境 j：看過的用實際對錯，沒看過的用預測的答對機率
lam = len(seen_j) / len(items_j)
p_unseen = [p_correct(theta_hat, alpha[i], beta[i]) for i in unseen_j]
z_pirt = lam * np.mean(y[seen_j]) + (1 - lam) * np.mean(p_unseen)

作者說這個想法的好處，是可以用 IRT 模型估模型在沒看過的資料上的表現。估出的 θ 若能用很多情境的資料，效果特別好：即使每個情境只看了幾題，p-IRT 也能用上所有看過的題，讓每個情境的估計都更好。在訓練集給定的條件下，θ 用大量資料估出來時，p-IRT 的變異小；IRT 模型設定得合理時，偏差也小。

命題 4.1 談題目很多時的行為。假設所有題目參數的真值都已知、α 的長度有上界，而且估出的 θ 在看過的題數趨近無限時依機率收斂到真值，那麼 p-IRT 也會依機率收斂到上面那個「最好的近似」。附錄 C 的證明只用了兩件事：邏輯斯函數的斜率最多 1/4，以及 Cauchy–Schwarz 不等式。

作者也點出 p-IRT 的兩個限制，它們在實務上會削弱它的效果。第一，它沒辦法直接使用樣本權重，所以用不上錨點的權重；第二，如果預測的答對機率不準，例如 IRT 模型設錯了，p-IRT 的表現就會變差。下一章的 gp-IRT 就是為了補這兩點。附錄 A 另外說明，子情境題數不同時，p-IRT 裡看過與沒看過的兩段都要乘上子情境的平衡權重。

提醒

看過的題越少，估計越依賴 IRT

看過的比例，就是看過的題佔情境題數的比例。以 MMLU 為例，約 1.4 萬題裡只考 100 題，看過的比例大約只有 0.7%；AlpacaEval 2.0 共 805 題，考 100 題時約 12.4%。這兩個比例是整理者用原文的題數算的。換句話說，在 MMLU 上，p-IRT 的分數有九成九以上來自 IRT 的預測：IRT 設得準，這是優點；設不準，那一大段就一起偏掉。

gp-IRT（generalized p-IRT）是作者最後的估計量。挑完題、做完題之後，先算出兩個估計：第 3 章的加權平均（隨機抽樣或錨點），以及上一章的 p-IRT。gp-IRT 是兩者的凸組合：λ 乘上加權平均，加上 1 − λ 乘上 p-IRT；λ 介於 0 與 1 之間，選來讓這個估計量表現最好（式 4.4）。

怎麼選 λ，要看兩個估計各有什麼毛病。隨機抽樣或錨點的加權平均偏差低，但題目少時變異可能很大，題目變多，變異就下降。p-IRT 反過來：在訓練集給定的條件下它的變異小，θ 用很多情境的資料估時更小；但 IRT 模型設錯時偏差可能很大，而且不會隨題數增加而消失。所以好的 λ 應該隨看過的題數增加。

作者的 λ 來自 Song（1988）的推論 2 導出的經驗法則：兩個估計量的最佳線性組合（權重加總為 1），取決於兩者的偏差、變異與共變異。如果第一個估計量沒有偏差、第二個的變異是零，最佳的 λ 是「第二個的偏差平方」除以「第二個的偏差平方加上第一個的變異」。作者假設阻礙 gp-IRT 的主要因素，就是第一個估計量的變異與第二個的偏差，所以把第一個的偏差與第二個的變異都近似成零。第一個估計量來自隨機抽樣時，λ ＝ b² ÷（σ² ÷ n ＋ b²），n 是看過的題數，b² 與 σ² 都是從訓練資料估出來的常數（論文的符號帶帽）。σ² 是訓練集裡各模型正確度的樣本變異數的平均；b² 是 IRT 偏差平方的估計，作法如下：

1
切兩組模型把訓練集的模型分成兩組。
2

3

def gp_irt(y_sel, w_sel, z_pirt, sigma2, b2, anchors=True):
    raw = (w_sel * y_sel).sum()              # 錨點或隨機抽樣的加權平均
    if anchors:
        sigma2 = sigma2 / 4                  # 錨點的變異較小：預設除以 4
    lam = b2 / (sigma2 / len(y_sel) + b2)    # IRT 偏差越大、題越多，越信 raw
    return lam * raw + (1 - lam) * z_pirt

思考題 · 02

2% 的誤差，夠你分辨兩個版本嗎？

假設你要比較同一個 agent 的兩個版本，完整評估上它們差 3 個百分點。如果每個版本都只考 tiny 版，各自有約 2% 的估計誤差，你還能相信「新版比較好」這個結論嗎？

先看你要偵測的差距有多大：差距比估計誤差大很多時，tiny 版就夠用；差距和誤差差不多時，改看排名相關，或對最後的候選版本跑一次完整評估。也要記得 2% 是平均，圖 6 裡個別模型最多到 4%。這個判斷方式是整理者的建議，論文沒有討論兩個版本的比較。

思考題 · 03

你的下一個模型，作答模式會和舊模型一樣嗎？

想像你用過去一年各版本 agent 的逐題結果挑出一組錨點。下一版換了底層模型、加了一個新工具，或改成只做某個領域。

改動越接近「整體變強」，錨點越可能還準；改動越接近「某一類題突然會了、另一類題突然不會」，就越像作者說的破口。實務上可以在大改版之後跑一次完整評估，拿來檢查 tiny 版的誤差，順便把這一版加進訓練資料、更新錨點。這是整理者依第 6.2 節延伸的建議。

圖 10 比較兩組題目在 MMLU 57 個科目上的總權重，作者說兩者的科目權重相當不同。正文說權重最高的三個科目是 high school psychology、elementary mathematics、professional law；圖 10 上有標名字的點裡，IRT 權重最高的三個則是 professional law、prehistory、professional medicine，elementary mathematics 沒有標出名字。v1 的文字與圖就已經是這樣，這一頁兩邊照寫。

背景

有效樣本數在算什麼

假設 100 題裡有一題的權重是 0.5，其餘 99 題分剩下的一半，那麼估出來的分數有一半取決於那一題，實際上「有用到」的題比 100 少很多。ESS 就是把這種不平均換成一個比例：權重完全平均時是 1，越集中在少數題越小。論文沒有寫 ESS 的式子；常見的算法是權重總和的平方除以權重的平方和，再除以題數。這一段是整理者補的背景。

Chapter 11 · Related Work

先前用 IRT 排名次，這篇用它估分數

第 1.1 節把相關研究分成三條線：少考幾題的高效評估、IRT 在 NLP 的應用、動態挑題的主動測試。作者說，就他們所知，IRT 還沒有被用在 LLM 的高效評估裡估分數。

高效評估 LLM。多資料集的基準隨著預訓練模型進入 NLP，一路跟著語言模型的能力演變；模型與資料集越來越大，評估成本跟著變高，也讓大家開始調整報告評估結果的方式來因應成本。Ye 等人研究過減少 Big-bench 的任務數；Perlitz 等人發現 HELM 的評估靠的是資料集之間的多樣性，但目前用的題數太多，這篇採用他們的分層抽樣當其中一種策略；Vivek 等人提出依模型對正確類別的信心把題目分群，加速分類任務的評估，這篇的其中一種方法，就是把它改到任務更多樣的 LLM 基準上。

試題反應理論。IRT 是心理計量學發展成熟的一組統計模型，透過標準化考試量測個人的潛在能力，例如 GRE、SAT。近年它在 AI 與 NLP 越來越常見：Lalor 等人提議用 IRT 的潛在變數量語言模型的能力；Vania 等人用 IRT 研究常用基準的飽和，也就是分不出模型的好壞；Rodriguez 等人研究了 IRT 在語言模型的幾種應用，認為它能可靠地預測 LLM 對沒看過的題的反應、依難度或鑑別度替題目分類，以及替模型排名。更近的 Zhuang 等人用 IRT 做自適應測驗，讓測驗更有效率；作者指出他們沒有提出 LLM 的表現估計量，只依能力參數替模型排名。

主動測試。另一條線和主動學習有關，特別是主動測試：用各種準則動態地挑評估題目，以降低標註成本。作者說這些方法和他們在第 6 節討論的自適應 IRT 有些相似（第 12 章）。

Chapter 12 · Conclusion · Extensions · Limitations

少考幾題可以，錨點要跟著新模型更新

作者的結論是：借用心理計量學的模型，只用基準的一小部分題就能準確評估 LLM。兩個延伸有初步結果：評估 prompt 模板，以及邊考邊挑題的自適應測驗。主要的限制是嚴重的分布偏移，作者建議定期用新模型的資料更新錨點與 IRT 參數。

第 6.1 節提了兩個延伸。第一個是評估 prompt。用 prompt 評估模型時，一直有個難題：prompt 的寫法會影響模型的預測。作者認為前面的方法可以用來跨 prompt 設定做預測：只做少數幾次評估，就估出一個模型在一組新 prompt 上的表現，或一個新模型在某個 prompt 上的表現。為了測這個想法，他們在 Weber 等人的預測資料上訓練 IRT 模型：8 個 LLaMA 模型（原版，或用 Alpaca 的 self-instruct 資料做過指令微調）在 ANLI 資料集上的評估，750 題各用 15 種指令模板包裝，模板取自 promptsource（P3）。

和前面的實驗一樣，他們試了隨機切，以及幾種有分布偏移的切法：依模型大小切，把 7B、13B、30B 的模型放訓練、65B 的放測試；依模板切，一種是 2 折交叉驗證、輪換指令模板，另一種是讓 in-context 範例與輸入題目用相同或不同的模板，並在訓練與測試集之間交換這兩種做法。圖 7 的結果顯示，即使有幾種實際的分布偏移，用這篇的方法評估 prompt 仍然有效率，作者說這是有前景的應用。

第二個是自適應測驗。與其在評估前先挑好一組題，也可以在評估的過程中動態挑題，許多標準化考試背後的電腦化測驗就是這樣做。作者在 MMLU 上用一個自適應的 IRT 變體做了初步實驗（圖 8，其他基準在附錄 E.5 的圖 16）：估計有改善，但目前的實作要跑 5 分鐘以上，實務上可能沒那麼吸引人。

限制（第 6.2 節）。主要的限制是可能遇到嚴重的分布偏移：簡單題答錯、難題答對的模型，架構或預訓練資料的大改，以及能力快速提升造成的外插誤差（第 9 章）。作者的建議是定期用較新的 LLM 的資料，更新挑好的題目與 IRT 參數。

散在正文的前提，也放在一起看：挑錨點與擬合 IRT，都要一批考過完整份的模型的逐題資料，Leaderboard 有 395 個，HELM 只有 30 個；誤差是測試模型的平均，個別模型最多到 4%（圖 6）；圖 4 的數字來自作者挑的一個種子；非二元的分數要先二值化；AlpacaEval 就算只考 100 題，每一題仍然要 GPT-4 當評審。

每個情境 100 題一定夠嗎？
論文的結論是：表現最好的策略在每個情境 100 題以內，四個基準的平均誤差約 2%；Open LLM Leaderboard 甚至每個情境 30 題就夠。但這是測試模型的平均，圖 6 裡個別模型最多到 4%，另外有一個表現極低的模型例外。
用 tiny 版需要自己訓練什麼嗎？
不用。作者釋出了挑好的題與權重，也釋出在各基準上訓練好的 IRT 參數與 gp-IRT 程式，在 CPU 上幾秒就能跑完。要替新的基準做自己的 tiny 版，才需要一批模型的逐題作答來挑錨點、擬合 IRT。
新出的模型也能用嗎？
依日期切、專門模型、把測試期拉到 3 到 6 個月的實驗裡，IRT 系的方法都相當穩。作者也說，作答模式大變的模型可能讓誤差變大，建議定期用新模型的資料更新題目與 IRT 參數。
整理者的讀法

放回這一講：agentic benchmark 能不能少考幾題

下面是整理者的連結，論文本身只做了靜態的 LLM 基準。這一講談的 agentic benchmark，每一題都要準備環境、跑一段多步驟的 agent 軌跡、再評分，一題的成本遠高於一道選擇題，少考幾題的誘因只會更大。但這篇的方法有兩個前提，放到 agentic benchmark 上要先檢查：第一，要有很多個模型或 agent 版本的逐題結果，錨點與 IRT 才有東西可學，而 agentic benchmark 常常題數少、公開的逐題結果也少；第二，scaffolding、工具或底層模型一換，作答模式就可能整個改變，正好是作者點名的分布偏移。比較穩的用法，是把 tiny 版當成開發期間的快速檢查，重要的比較仍然跑完整評估。

benchmark
基準
一整套考題與計分方式；這篇用 Open LLM Leaderboard、MMLU、HELM、AlpacaEval 2.0 四個。
scenario／sub-scenario
情境與子情境
基準裡的一份考卷，和考卷裡的分類；MMLU 算一個情境，57 個科目是子情境（第 2 節）。
example（item）
題目
一道題；IRT 的文獻叫 item。
correctness
正確度
模型在一道題的得分，0 或 1，或 0 到 1 之間；論文記作 Y。
balance weights
平衡權重
子情境題數不同時，讓每個子情境一樣重的題目權重（附錄 A）。
stratified random sampling
分層隨機抽樣
以子情境為層均勻地抽，題數最多差 1，每題權重相同；圖上的 random。
anchor points
錨點
分群後離每個群中心最近的題，權重是那一群佔的比例（第 3.2 節）。
K-means
K 平均分群
把向量分成 K 群、讓點靠近群中心的演算法；這篇用它挑錨點。
IRT
試題反應理論
心理計量學的模型，用考生的能力與題目的參數預測答對機率（第 4.1 節）。
θ（ability）
能力參數
每個模型一個 d 維向量，代表看不到的能力；新模型只要估它。
α、β
能力需求與偏移
每道題的參數：α 決定需要哪些能力，β 越大越難答對；合起來是題目向量。
variational inference
變分推論
用簡單的分布逼近參數分布的擬合方法；這篇取變分分布的平均當點估計（第 4.4 節）。
p-IRT
表現 IRT 估計量
看過的題用實際對錯、沒看過的用預測機率，依題數比例合成情境分數（式 4.3）。
gp-IRT
廣義 p-IRT
加權平均與 p-IRT 的凸組合，λ 依題數與 IRT 偏差決定（式 4.4）；圖上的「++」。
bias／variance
偏差與變異
估計值平均離真值多遠，以及重抽時晃得多大；gp-IRT 用它們選 λ。
estimation error
估計誤差
少數題估出的分數和完整基準真實分數的差距；圖上多是測試模型的平均。
Spearman（rS）
等級相關
只比排名的相關係數，1 代表估出的排名和真實排名完全一致。
distribution shift
分布偏移
要估的新模型和挑題用的舊模型不一樣；依日期切與專門模型都在測它。
specialized LLM
專門模型
針對程式、生物、金融等領域微調的模型；第 5 節手挑了 40 個。

平均勝率

ESS
有效樣本數

adaptive testing
自適應測驗
